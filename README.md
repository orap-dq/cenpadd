Es solo una sugerencia de GitHub y puedes ignorarla. No afecta en nada a la app.

Si quieres aprovechar y ponerlo de una vez (le da una presentación más formal al repositorio), da clic en **Add a README**, borra lo que traiga, pega este texto y da clic en **Commit changes**:

```markdown
# CENPADD
**Censo Parroquial Digital Diocesano**

Aplicación web instalable (PWA) para el levantamiento del censo parroquial en la Diócesis de Querétaro.

Proyecto del **ORAP** – Observatorio de la Realidad y la Acción Pastoral,
Vicaría Episcopal de Pastoral, Diócesis de Querétaro.

**App:** https://orap-dq.github.io/cenpadd/

> Versión de prueba.
```

Lo pongas o no, el siguiente paso es el mismo: **Settings → Pages**, *Deploy from a branch*, **main** y **/ (root)**, luego **Save**.
